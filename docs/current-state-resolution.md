# Current-state resolution

Crave Hunt now treats operational state as a derived conclusion from dated observations, not a mutable truth field.

## Resolution order

1. Primary/official current evidence.
2. Independent current reporting.
3. Multiple independent observations that agree.
4. High-quality map/business records.
5. Community signals and discovery leads.

Repeated copies of one upstream claim do not count as independent corroboration.

## State logic

- One current observation + no contradiction = provisional state.
- Two independent agreeing observations = corroborated state.
- Conflicting current observations = uncertain + automatic recheck.
- Historical evidence never disappears when current state changes.
- Community-only closure/open claims cannot establish final current state.
- Planned infrastructure remains planned until current operational evidence exists.

## Public timeline contract

Entity pages should expose:
- current derived state
- confidence
- last checked date
- observation timeline
- source role
- contradiction count
- next recheck action

The UI must distinguish verified fact, dated observation, community signal, discovery lead and unresolved conflict.

## Why

A food archive has two truths to preserve simultaneously: what a place was, and what it is now. Overwriting the former destroys archive value; trusting one stale aggregator destroys current accuracy. The resolver therefore derives current state while retaining the evidence history.
